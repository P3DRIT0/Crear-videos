# Arquitectura y contratos

## Estructura objetivo
apps/dashboard (Next), apps/api (FastAPI), services/orchestrator, services/workers/{cpu,gpu,publisher}, packages/contracts, agents, workflows, presets, integrations, infra, tests, docs. Un monorepo; no multiplicar servicios sin justificación. Python 3.11/3.12 y Node LTS compatibles con dependencias comprobadas; fijar versiones y lockfiles. Separar entorno de ComfyUI del backend para evitar conflictos PyTorch.

## Flujo
Brand → Campaign → Idea → Script → Storyboard → Shot → RenderAttempt → Asset → Edit → Review → Publication → MetricsSnapshot. Workflow durable en Temporal: preparar → guion → aprobar opcionalmente → storyboard → generar planos → QC → audio → montaje → QC final → aprobación humana → publicación opcional → analítica. LangGraph produce JSON validado para decisiones acotadas; no controla reintentos ni estados persistentes globales. Un job GPU activo como máximo. Los workflows almacenan IDs, no binarios. Persistir decisiones y versiones de prompts. Ante reinicio, reanudar sin duplicar efectos; una publicación con resultado incierto se reconcilia antes de reintentar.

## Entidades
Brand(id, name, voice, palette, audience, rules, locale); Character(id, brand_id, reference_assets, style_version); Campaign(id, brand_id, objective, schedule); Script(id, version, hook, scenes, cta); Shot(id, script_version, order, duration, camera, visual_prompt, negative_prompt, refs, seed); RenderAttempt(id, shot_id, provider, model_version, workflow_version, status, error, timings, parameters); Asset(id, sha256, mime, path, dimensions, duration, provenance, license_status, simulated); Job(id, type, state, progress, attempts, correlation_id, heartbeat); Review(id, artifact_hash, verdict, reviewer, rubric); Publication(id, account_id, artifact_hash, approved_at, scheduled_at, external_id, status, idempotency_key); MetricsSnapshot(id, publication_id, observed_at, metrics, source). UUIDs, UTC en persistencia, Europe/Madrid en UI. Aislamiento por marca. No ejecutar HTML externo.

## API propuesta (versionada /api/v1)
CRUD brands, characters, campaigns, scripts, shots, assets; POST campaigns/{id}/produce; GET jobs/{id}; POST jobs/{id}/cancel y /retry; SSE events con reconexión; POST reviews; POST publications/{id}/approve y /schedule; GET system/capabilities; GET models; GET metrics. OpenAPI genera tipos frontend. Aprobación vinculada al hash exacto; cambios invalidan aprobación. Mutaciones idempotentes. Validar permisos y propiedad de marca. Descargas por ID, nunca rutas arbitrarias.

## Adaptadores
Interfaces tipadas: LLMProvider.generate(schema, messages), ImageProvider.submit(spec), VideoProvider.submit(spec), AudioProvider.submit(spec), Renderer.compose(timeline), Publisher.publish(approved_asset), ResearchProvider.search(query), MetricsProvider.fetch(post_id). Generación asincrónica vía submit/status/cancel/collect; resultado incluye manifest, semilla, parámetros, versión, métricas de recursos y estado simulated. Clasificar errores (retryable/permanent/unknown). Implementar mocks deterministas primero; ningún proveedor puede acceder a Internet en modo offline. Ollama HTTP local; ComfyUI /prompt, historial y eventos según versión comprobada, workflows JSON API fijados. FFmpeg mediante argumentos sin shell, ffprobe para validar salida. Meta/Postiz en plugin aislado, desactivado por defecto; evaluar documentación actual, OAuth, cuentas profesionales, permisos y hosting temporal permitido para media si el endpoint lo exige. No exponer el PC doméstico automáticamente.

## Agentes
Director creativo, productor, investigador, estratega social, planificador, guionista, storyboard, director artístico, diseñador de personajes, director de fotografía, animador, diseñador sonoro, director de voz, editor, inspector visual, publicador, analista. Roles lógicos que comparten un LLM; no 17 modelos simultáneos. Cada rol define input/output JSON, herramientas permitidas, timeout, presupuesto de pasos, política de fallback, versión de prompt y evaluación. El productor orquesta tareas con reglas deterministas. El publicador no puede aprobarse a sí mismo. Agency Agents e Instagram Skills se auditan como material de referencia, no como dependencias ejecutables indiscriminadas.

## UI
Overview, Brands, Characters, Campaigns, Studio/Storyboard con tarjetas de planos y regeneración selectiva, timeline no destructiva, Assets, Jobs/Agents, Approvals, Calendar, Analytics, Models, System. Estados reales, errores accionables, duración estimada solo si hay datos, indicador MOCK/OFFLINE, vista 9:16, historial de versiones y comparador de renders. Diseño sobrio oscuro, responsive, teclado y accesibilidad.
